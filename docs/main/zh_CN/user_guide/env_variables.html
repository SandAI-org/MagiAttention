正确性相关#

MAGI_ATTENTION_FORWARD_HIGH_PRECISION_REDUCE

  • 默认值： 0

  • 使用方： magi_attention.env.comm.is_fwd_high_precision_reduce_enable

将此环境变量设为 1 以启用 dist-attn 前向传播中 partial out 的高精度（fp32）reduce，以双倍通信开销换取更高精度和更少的 dtype 转换开销。

备注

  1. 在 ffa 前向内核内部，我们始终对 partial out 使用高精度（fp32）累加。

  2. 我们在所有地方始终使用高精度（fp32）的 lse。

  3. 此功能仅在启用 qo comm 时对 out 生效。

MAGI_ATTENTION_BACKWARD_HIGH_PRECISION_REDUCE

  • 默认值： 0

  • 使用方： magi_attention.env.comm.is_bwd_high_precision_reduce_enable

将此环境变量设为 1 以启用 dist-attn 反向传播中 partial dq,dk,dv 的高精度（fp32）reduce，以双倍通信开销换取更高精度和更少的 dtype 转换开销。

备注

  1. 在 ffa 反向内核内部，我们始终对 partial dq,dk,dv 使用高精度（fp32）累加。

  2. 此功能仅在启用 qo comm 时对 dq 生效。

MAGI_ATTENTION_DSINK_ALL_REDUCE_OP

  • 默认值： none（可选值：none、sum、avg）

  • 使用方： magi_attention.env.comm.dsink_all_reduce_op

设置此环境变量的值以控制涉及 attention sink 时 dist_attn_func 中 sink 梯度的 all-reduce 操作。

备注

目前我们仅接受全局复制的 sink 张量作为输入传入 dist_attn_func，每个 cp rank 中的 sink 梯度是部分的，需要在 cp rank 之间进行 sum-reduce。

然而，由于 sink 张量是可学习的，它将被视为模型中的常规参数，类似于 nn.Linear 层中的 bias。

因此在一些流行的训练框架（如 Megatron-LM、FSDP）中，sink 部分梯度在 cp rank 之间的 sum-reduction 可能会在整个 dp x cp mesh 中自动执行。

为避免重复 reduction，我们提供此环境变量来指定 dist_attn_func 中 sink 梯度的 all-reduce 操作，其默认值为 none，即 dist_attn_func 不对 sink 梯度执行任何 reduction，而由框架来处理。

但在没有任何框架机制来跨 cp rank reduce 参数的场景下，您必须将此环境变量设为 sum。

有时 avg 也是一个选项，当您需要将 sink 梯度按 1/cp 缩放时可以使用。

运行时相关#

MAGI_ATTENTION_LOG_LEVEL

  • 默认值： WARN

  • 使用方： magi_attention.env.general.log_level

设置此环境变量以控制整个 magi_attention 包的日志详细程度。有效值（不区分大小写）为 DEBUG、INFO、WARN、WARNING、ERROR、CRITICAL。

MAGI_ATTENTION_KERNEL_BACKEND

  • 默认值： ffa

  • 使用方： magi_attention.env.general.kernel_backend

设置此环境变量以选择注意力内核后端。有效值为：

  • ffa：flex-flash-attention（默认，高性能持久化内核）。

  • sdpa：离线 SDPA 实现（用于测试 / fp32、fp64 等高精度）。

  • sdpa_ol：在线（分块）SDPA 实现（用于测试，显存占用低于 sdpa）。

  • fa4：Flash-Attention 4 monkey patch（Blackwell GPU 的临时方案）。

备注

此变量取代了旧的 MAGI_ATTENTION_SDPA_BACKEND=1 和 MAGI_ATTENTION_FA4_BACKEND=1 开关，后者仍受支持，但不得与 MAGI_ATTENTION_KERNEL_BACKEND 同时设置。

MAGI_ATTENTION_PRECISION

  • 默认值： 未设置（保持输入 dtype 不变）

  • 使用方： magi_attention.env.general.precision

设置此环境变量以覆盖注意力内核的计算 dtype。有效值为 bf16、fp16、fp32、fp64。设置后，输入 Q/K/V 会在注意力计算前转换为指定 dtype，输出再转换回原始输入 dtype。

性能相关#

FFA BWD Kernel Tuning (Advanced)#

The following environment variables control low-level kernel configuration for the backward pass. They override compile-time defaults and produce distinct JIT-cached kernels per configuration. For expert use only — incorrect combinations may cause correctness issues or crashes.

MAGI_ATTENTION_FFA_BWD_PRODUCER_REGS

  • Defaults to: auto (40 for sparse, 64 for dense)

  • Used by: _flex_flash_attn_jit.py → kBwdProducerRegs / kBwdConsumerRegs

Override the setmaxnreg register quota for the producer warp group. Consumer regs are derived to satisfy the per-SM register budget constraint: 1×ProducerRegs + 2×ConsumerRegs ≤ 504.

MAGI_ATTENTION_FFA_BWD_TILE_M / MAGI_ATTENTION_FFA_BWD_TILE_N

  • Defaults to: 0 (auto from tile_size_bwd_sm90())

  • Used by: kBwdTileM / kBwdTileN in the kernel

Override the MMA tile dimensions (M×N) for the backward kernel. Common values: 64, 128.

MAGI_ATTENTION_FFA_BWD_STAGES / MAGI_ATTENTION_FFA_BWD_STAGES_DS / MAGI_ATTENTION_FFA_BWD_STAGES_V

  • Defaults to: 0 (auto: stages=2, stages_ds=1 or 2, stages_v=stages)

  • Used by: kBwdStages / kBwdStagesDs / kBwdStagesV

Override the number of pipeline stages for K (main pipeline), dS (double buffer), and V.

MAGI_ATTENTION_FFA_BWD_UNION_DKV_SMEM

  • Defaults to: 0 (smem_inner_dk and smem_inner_dv are unioned into one buffer)

  • Used by: UnionDkvSmem template parameter

Set to 1 to un-union dK/dV SMEM (separate buffers for each). Requires stages_v=1 to fit.

MAGI_ATTENTION_FFA_BWD_DKV_USE_SMEM

  • Defaults to: 1 (use SMEM for inner dKV store)

  • Used by: kInnerStoreMode (0 forces InnerStoreMode::BypassSmem)

Set to 0 to bypass SMEM for dKV — consumer WGs atomicAdd directly to GMEM from registers. Experimental; may improve performance for bandwidth-bound configs.

MAGI_ATTENTION_FFA_INNER_LOAD_MODE

  • Defaults to: auto (tma when tiles are contiguous, else cpasync)

  • Used by: kInnerLoadMode enum (Tma=0, CpAsync=2)

Override the inner-loop load method. Options: tma, cpasync.

MAGI_ATTENTION_FFA_INNER_STORE_MODE

  • Defaults to: tma (2D reduce-add for sparse, or auto for dense)

  • Used by: kInnerStoreMode enum (Tma=0, Tma1d=1, AtomicAdd=2, BypassSmem=3)

Override the inner-loop store method. Options: tma, tma2d, tma1d, atomicadd, bypass.

MAGI_ATTENTION_FFA_INNER_STORE_IN_PRODUCER

  • Defaults to: true

  • Used by: InnerStoreInProducer template parameter

Set to false to have consumer WGs handle dX store directly (frees producer warps for loading but increases consumer register pressure).

MAGI_ATTENTION_FFA_INNER_DIR_MAX_TO_MIN

  • Defaults to: true

  • Used by: InnerDirMaxToMin template parameter

Set to false to iterate the inner loop from min to max instead of max to min.

MAGI_ATTENTION_FA4_BACKEND

  • 默认值： 0

  • 使用方： magi_attention.env.general.kernel_backend

将此环境变量设为 1 以将注意力内核后端从 FFA 切换到 FFA_FA4——Flash-Attention 4 的 monkey patch 版本，以临时支持 Blackwell GPU 上的任意掩码。

备注

这是为向后兼容保留的旧开关；推荐使用 MAGI_ATTENTION_KERNEL_BACKEND=fa4。这目前是一个临时解决方案，未来可能会被移除或更新。

MAGI_ATTENTION_NATIVE_GRPCOLL

  • 默认值： 0

  • 使用方： magi_attention.env.comm.is_native_grpcoll_enable

将此环境变量设为 1 以启用 group collective 通信的原生内核实现。

备注

此功能目前处于实验阶段并在积极开发中，与许多其他功能不兼容，因此请不要启用，除非您清楚了解其影响。

MAGI_ATTENTION_QO_COMM

  • 默认值： 0

  • 使用方： magi_attention.env.comm.is_qo_comm_enable

将此环境变量设为 1 以启用 query/output 通信，包括获取远程 q（前向）、reduce partial out 和 lse（前向）、获取远程 q,o,lse,do（反向）、reduce partial dq（反向），以消除通信仅限于 key/value 的限制。

备注

此功能目前处于实验阶段并在积极开发中，与许多其他功能不兼容，因此请不要启用，除非您清楚了解其影响。

MAGI_ATTENTION_FLATTEN_HEAD_GROUPS

  • 默认值： 0

  • 使用方： magi_attention.env.general.is_flatten_head_groups_enable

将此环境变量设为 1 以展平 GQA/MQA attention 中的 head groups 来优化 dynamic solver 性能。

备注

此功能目前处于实验阶段并在积极开发中，与许多其他功能不兼容，因此请不要启用，除非您清楚了解其影响。

MAGI_ATTENTION_RANGE_MERGE

  • 默认值： 0

  • 使用方： magi_attention.env.general.is_range_merge_enable

将此环境变量设为 1 以启用 flex-flash-attention 的自动范围合并，通过减少注意力范围的数量来提升性能。

备注

此功能目前处于实验阶段并在积极开发中，因此请不要启用，除非您清楚了解其影响。

MAGI_ATTENTION_CATGQA

  • 默认值： 0

  • 使用方： magi_attention.env.general.is_cat_gqa_enable

将此环境变量设为 1 以启用 flex-flash-attention 反向的 CatGQA 模式，通过拼接共享相同 KV head 的多个 Q head 来进一步优化 GQA 设置下的性能。

备注

此功能目前处于实验阶段并在积极开发中，因此请不要启用，除非您清楚了解其影响。

MAGI_ATTENTION_BWD_HIDE_TAIL_REDUCE

  • 默认值： 0

  • 使用方： magi_attention.env.general.dist_attn_backward_hide_tail_reduce

将此环境变量设为 1 以牺牲保存最后一个远程 kv 激活来重排反向传播中的重叠阶段，将最终的远程 group_reduce 隐藏在主机 FFA 阶段中。

备注

此功能目前处于实验阶段并在积极开发中，与许多其他功能（如 qo comm）不兼容，因此请不要启用，除非您清楚了解其影响。

MAGI_ATTENTION_MIN_CHUNKS_PER_RANK

  • 默认值： 8

  • 使用方： magi_attention.env.general.min_chunks_per_rank

设置此环境变量的值以控制每个上下文并行 rank 的最小 chunk 数量，从而控制计算负载均衡的粒度。

MAGI_ATTENTION_FFA_FORWARD_SM_MARGIN

  • 默认值： 当 CUDA_DEVICE_MAX_CONNECTIONS > 1 时为 4，否则为 0

  • 使用方： magi_attention.env.comm.ffa_fwd_sm_margin_save_for_comm

设置此环境变量的值以控制 ffa 前向内核为通信内核预留的 SM 数量。

MAGI_ATTENTION_FFA_BACKWARD_SM_MARGIN

  • 默认值： 当 CUDA_DEVICE_MAX_CONNECTIONS > 1 时为 4，否则为 0

  • 使用方： magi_attention.env.comm.ffa_bwd_sm_margin_save_for_comm

设置此环境变量的值以控制 ffa 反向内核为通信内核预留的 SM 数量。

MAGI_ATTENTION_CPP_BACKEND

  • 默认值： 0

  • 使用方： magi_attention.env.general.is_cpp_backend_enable

将此环境变量设为 1 以启用核心数据结构（AttnRange、AttnMaskType 等）的 C++ 后端，以避免 Python 开销。

备注

此功能目前处于实验阶段并在积极开发中。如果未找到 C++ 扩展或此变量设为 0，将回退到 Python 实现。

MAGI_ATTENTION_HIERARCHICAL_COMM

  • 默认值： 0

  • 使用方： magi_attention.env.comm.is_hierarchical_comm_enable

将此环境变量设为 1 以启用二维 cp group（inter_node group + intra_node group）内的分层 group-collective 通信。

备注

这目前是减少冗余节点间通信的临时方案，未来可能会被移除或更新。

MAGI_ATTENTION_DIST_ATTN_RUNTIME_DICT_SIZE

  • 默认值： 1000

  • 使用方： magi_attention.env.general.dist_attn_runtime_dict_size

设置此环境变量的值以控制 dist_attn_runtime_dict_mgr 的最大 LRU 缓存大小。

CUDA_DEVICE_MAX_CONNECTIONS

  • 默认值： 8

  • 使用方： magi_attention.env.general.is_cuda_device_max_connections_one

此环境变量定义了 CUDA stream 可以使用的硬件队列数量。增大此值可以改善通信与计算的重叠，但也可能增加 PCIe 流量。

此功能仅用于测试或调试，因为额外的健全性检查开销可能不容忽视。

MAGI_ATTENTION_SDPA_BACKEND

  • 使用方： magi_attention.env.general.kernel_backend

将此环境变量设为 1 可将注意力内核后端从 ffa 切换到 sdpa-math，以支持更高精度（如 fp32 或 fp64）。

备注

这是为向后兼容保留的旧开关；推荐使用 MAGI_ATTENTION_KERNEL_BACKEND=sdpa。此功能仅用于测试或调试，因为其性能不可接受。

MAGI_ATTENTION_DETERMINISTIC_MODE

  • 默认值： 0

将此环境变量设为 1 以启用确定性模式，对所有 magi_attention 内核使用确定性算法。

MAGI_ATTENTION_PROFILE_MODE

  • 默认值： 0

MAGI_ATTENTION_FFA_CUTEDSL_DEBUG_MODE

构建相关#

JIT#

MAGI_ATTENTION_WORKSPACE_BASE

  • 默认值： $HOME

  • 使用方： magi_attention.env.build.workspace_base_dir

指定 MagiAttention 工作空间的基础目录，包含缓存和生成的源文件。

MAGI_ATTENTION_BUILD_VERBOSE

  • 默认值： 0

  • 使用方： magi_attention.env.build.is_build_verbose

将此环境变量设为 1 以启用 JIT 编译过程中的详细输出，显示正在执行的完整 ninja 构建命令。

MAGI_ATTENTION_BUILD_DEBUG

  • 默认值： 0

  • 使用方： magi_attention.env.build.is_build_debug

将此环境变量设为 1 以启用 C++/CUDA 编译器的调试标志。这包括 -g（调试符号）等选项和其他用于获取更详细信息（如寄存器使用情况）的标志。

MAGI_ATTENTION_NO_BUILD_CACHE

  • 默认值： 0

  • 使用方： magi_attention.env.build.is_no_build_cache

将此环境变量设为 1 以禁用已构建 ffa 内核的缓存。

MAGI_ATTENTION_FORCE_JIT_BUILD

  • 默认值： 0

  • 使用方： magi_attention.env.build.is_force_jit_build

将此环境变量设为 1 以强制以 JIT 模式构建 FFA，即使预构建的 AOT libs 已存在。

NVCC_THREADS

  • 默认值： 4

  • 使用方： magi_attention.env.build.nvcc_threads

设置 nvcc 的 --split-compile 选项的线程数，可加速 CUDA 内核的 JIT 编译。

MAGI_ATTENTION_JIT_COMPILE_DISABLED

  • 默认值： 0

  • Used by: magi_attention.common.jit.core.JitSpec.build_and_load

Toggle this env variable to 1 to forbid JIT compilation at runtime. If a kernel is not found in the AOT or JIT cache, a RuntimeError is raised immediately instead of compiling on the fly. Useful for CI to verify that all required kernels have been precompiled — any missing kernel surfaces as a clear error with the kernel name and searched paths.

MAGI_ATTENTION_FFA_CUTEDSL_CACHE_ENABLED

  • 默认值： 0

  • 使用方： magi_attention.kernel.cutedsl.cache_utils

将此环境变量设为 1 以启用已编译 CuteDSL FFA 内核的磁盘缓存。

MAGI_ATTENTION_FFA_CUTEDSL_CACHE_DIR

  • 默认值： 未设置（使用默认缓存位置）

  • 使用方： magi_attention.kernel.cutedsl.cache_utils

设置此环境变量以指定 CuteDSL FFA 内核缓存的目录。

AOT#

MAGI_ATTENTION_PREBUILD_LEVEL

  • Defaults to: lite

  • 使用方： setup.py

Controls the breadth of FFA kernel configurations pre-built during pip install.

  • lite (default): Pre-builds only the basic Dense kernels (fwd/bwd × head_dim 64/128 × fp16/bf16 × atomic/non-atomic). Sufficient for most inference and training workloads.

  • ci: Additionally pre-builds all kernel variants declared by test classes via precompile_kernel_specs(). Eliminates JIT compilation during test runs.

备注

The CI workflow (build_test.yaml) explicitly sets MAGI_ATTENTION_PREBUILD_LEVEL=ci in the build step. For local builds, the default lite level is used unless overridden.

MAGI_ATTENTION_PREBUILD_FFA_JOBS

  • 默认值： ceil(num_cpu_cores * 0.9)

  • 使用方： setup.py

设置此环境变量的值以控制预构建 ffa 内核时使用的并行编译任务数。

MAX_JOBS

  • 默认值： ceil(num_cpu_cores * 0.9)

  • 使用方： setup.py

设置此环境变量的值以控制构建 ffa 以外的扩展模块时使用的并行编译任务数。

MAGI_ATTENTION_PREBUILD_FFA

  • 默认值： 1

  • 使用方： setup.py

将此环境变量设为 1 以启用对一些 ref_block_size=None 的常见选项预构建 ffa 内核，其余选项则以 JIT 模式构建。

MAGI_ATTENTION_SKIP_CUDA_BUILD

MAGI_ATTENTION_SKIP_MAGI_ATTN_EXT_BUILD

MAGI_ATTENTION_FFA_FA4_CACHE_DIR

  • 使用方： magi_attention.functional.fa4_utils

设置此环境变量以指定预编译 FFA_FA4 内核的缓存目录。

MAGI_ATTENTION_BUILD_COMPUTE_CAPABILITY

  • 默认值： 未设置（自动检测当前 GPU 设备）

  • 使用方： setup.py

设置此环境变量以指定构建 MagiAttention 扩展模块时使用的计算能力（影响 magi_attn_comm 和 create_block_mask）。支持逗号分隔的多架构值，例如 MAGI_ATTENTION_BUILD_COMPUTE_CAPABILITY=90,100。如果未设置，我们将尝试检测当前 GPU 设备的计算能力。如果检测失败将抛出错误。

MAGI_ATTENTION_ALLOW_BUILD_WITH_CUDA12

  • 默认值： 0

  • 使用方： setup.py

将此环境变量设为 1 以允许使用 CUDA-12 构建 MagiAttention 扩展模块，这可能导致与 CUDA-13+ 相比显著的性能下降。当为 0 时，如果 CUDA 版本低于 13.0，我们将抛出错误并中止安装。

NVSHMEM_DIR

  • 默认值： 系统模块 nvidia-nvshmem-cu12（如 requirements.txt 中所列）

  • 使用方： setup.py

设置此环境变量为自定义 nvshmem 安装目录的路径。

如果在任何位置都未找到，native group collective 通信内核中的所有相关功能将被禁用。
